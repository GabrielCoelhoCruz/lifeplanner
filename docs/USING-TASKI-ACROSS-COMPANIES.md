# Run two companies with Taski

Taski works best as a personal execution layer across both companies. Keep source documents, team conversations, and formal issue history in each company’s existing systems.

## Set up the structure

Create one context for each company. Keep `Pessoal` for work that belongs to neither company.

Inside each context, create projects for outcomes or ongoing workstreams:

- `Company A` → Client delivery, Operations, Hiring
- `Company B` → Product launch, Sales pipeline, Finance
- `Pessoal` → Admin, Learning

Avoid creating one project per small request. Create a task inside the relevant project instead.

## Capture useful tasks

Write task titles as visible next actions:

- Good: `Send revised proposal to Ana`
- Weak: `Proposal`

Use the fields consistently:

- **High:** work that creates risk when delayed.
- **Medium:** planned work that should move this week.
- **Low:** optional improvements and backlog work.
- **Due date:** the real commitment date, not an aspirational date.
- **Description:** links, acceptance criteria, decisions, and waiting details.
- **Checklist:** the concrete steps needed to finish the task.

If an issue lives in another system, add its link to the description. Taski should tell you what to do next, while the source system keeps the full record.

## Plan each day

1. Open **Hoje**.
2. Review overdue tasks before new work.
3. Filter by each company to check its commitments.
4. Return to **Todos** and choose the three most important tasks across both companies.
5. Complete tasks directly from the list.
6. Open the project when you need the checklist or supporting details.

Use the Pomodoro timer for the task you are actively working on. Do not use it as a time-reporting system.

## Review at the end of the day

Spend five minutes on each context:

1. Complete finished tasks.
2. Move unclear requests into the correct project.
3. Add a due date only when a real commitment exists.
4. Update the next action for work that is waiting on someone.
5. Check the next seven days in **Hoje**.

Export a JSON backup from **Configurações** after a large planning session or before importing data.

## Current boundary

Taski is a single-user planner. It does not replace company systems that need shared ownership, approvals, audit history, or team reporting. Use it to maintain your personal next-action view across those systems.
